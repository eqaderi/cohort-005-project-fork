# Pause course access as soon as a Refund Request is made

A learner loses access to a course the moment they make a Refund Request, not when the money goes back. Every request is reviewed by hand, so a decision can take days; if access stayed open while the request waited, a learner could finish the course and still be refunded. Access comes back if the request is Declined, and is removed for good once the Refund is Completed.

## Considered Options

- **Remove access when the Refund is Completed.** Kinder to a learner whose payout is slow or fails, but leaves the whole course open during review. Rejected for that reason.
- **Remove access when the request is Approved.** Still leaves the course open during review, and gives no extra protection over pausing on request.
